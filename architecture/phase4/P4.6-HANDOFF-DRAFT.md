## What P4.6 is

Flow control for the command outbox (contract R18, implemented as R36): bounded admission (a global and a per-device cap on unresolved delivery obligations, HTTP 429 for a manual command, a visible suppression for a rule-originated one, nothing written either way) and a publish-rate limit shared by every dispatcher instance (a database-derived sliding-window permit count inside the claim transaction; a command that must wait stays untouched and expires visibly if its window ends). Fail-closed when the limiter cannot decide, no busy loop, flag-OFF behaviour unchanged, no migration, new metrics (rejections, queue depth and utilization, deferrals, expiry while waiting, ingestion lag).

Authority and evidence: `reliability-contract.md` R36, `p4-acceptance-ledger.md` (section R and the P4.6 evidence section), `p4-implementation-ticket.md` (slice P4.6 status), `P4.5-TRACKED-FOLLOWUPS.md` (F3 added).
