## Validation scope

The P1.7 evidence and MQTT ACK evidence are **software/simulated validation**.
An `ACCEPTED` ACK is not a verified physical-world outcome. Existing Review III
hardware notes track physical tests separately (PIR, button, small LED, buzzer
tested; BME280 unverified; MQ-2 parked; servo/fan/relay not physically tested).
P2.0 will not expand physical hardware claims.
